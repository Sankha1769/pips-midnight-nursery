# Pip's Midnight Nursery: Baby's First Website (Track 1)
Static site. Open `index.html`, or deploy the folder to GitHub Pages / Vercel.
Features: music box (Web Audio), night-mode torch, scroll-drawn dream route, scroll story,
sparkle trail, odometer, click sounds + mute toggle, hidden Easter egg (tap Pip's pom-pom 3x).
Assets: official haX.baby Pip asset pack.
